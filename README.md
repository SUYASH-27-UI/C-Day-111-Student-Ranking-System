# Student Ranking & Performance System – C Day 111

## Description
A C program that manages student records and generates rankings based on marks.

## Features
- Add student records
- Prevent duplicate student IDs
- Display students in descending marks order
- Search students by ID
- Calculate class average
- Save student records in a text file

## Technologies
- C Programming
- Structures
- Pointers
- Standard Library

## Files
- `ranking.c`
- `students.txt`

## How to Compile
```bash
gcc ranking.c -o ranking
```

## How to Run
```bash
./ranking
```

## Concepts Used
Structures, Pointers, qsort(), Sorting, File Handling, Searching and Mathematical Calculations.
